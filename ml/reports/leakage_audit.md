## 1. Executive Summary & Root Cause Corrections

An earlier audit identified critical data leakage flaws in preliminary model baselines:
1. **Disaster Model Flaw**: Concurrent wind speed was used as an input feature while `is_hazard` was simultaneously defined as `wind >= 45 km/h`.
   - **Correction**: Redesigned to predict **future hazard state at time t+24h** (`target_hazard_24h`). Input features strictly measure historical and current variables at or before time t (t, t-6h, t-12h). Observations are partitioned strictly storm-disjointly so no storm system spans train and test.
2. **Weather Model Flaw**: Future targets were computed as a deterministic analytic function of the current row and seasonal trigonometric terms, yielding unrealistically small RMSEs.
   - **Correction**: Ingests realistic continuous synoptic and diurnal atmospheric variance. Separate models predict actual independent observations at t+6h, t+12h, t+24h, t+48h, and t+72h, rigorously benchmarked against persistence.
3. **PFZ Model Flaw**: Target `is_favorable` was generated by thresholding the exact same inputs (SST gradient, chlorophyll, depth) provided to the model.
   - **Correction**: Reformulated to predict **independent 48-hour future frontal persistence** under oceanographic mixing and advection. Built an extensible INCOIS advisory schema adapter in `ml/data_ingestion/incois_pfz.py` to transparently ingest official external records whenever available.

## 3. Automated Guardrail Checks

The pipeline enforces automated runtime assertions before training:
1. **Direct Target Derivation Test**: If target variable name or future measurement appears in feature matrix -> Pipeline terminates immediately.
2. **Correlation Sanity Boundary**: If abs(r(x_i, y)) > 0.98 for any continuous feature -> Pipeline terminates with `ValueError`.
3. **Chronological Barrier**: min(t_test) > max(t_train) strictly validated.
4. **Storm-Disjoint Partitioning**: Intersection of train and test storm unique identifiers must be strictly empty.
